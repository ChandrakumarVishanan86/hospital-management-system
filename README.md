# 🏥 Hospital Management System (HMS)

A complete Hospital Management System built using PHP & MySQL to manage patients, doctors, appointments and admin operations.

### ✨ Features
- 👨‍⚕️ Doctor Management
- 👤 Patient Management  
- 📅 Appointment Booking System
- 🔐 Admin, Doctor & Patient Separate Login
- 📊 Dashboard & Medical History

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP / WAMP / LAMP

### 🚀 How To Run This Project

1.  Download the zip file / Clone the repo
2.  Extract the Zip file   `hospital` folder
3.  Paste inside root directory:
    - For XAMPP: `xampp/htdocs/`
    - For WAMP: `wamp/www/`
    - For LAMP: `var/www/html/`
4.  Open PHPMyAdmin -> `http://localhost/phpmyadmin`
5.  Create a database with name `hms`
6.  Import `hms.sql` file (given inside the SQL file folder)
7.  Run the script: `http://localhost/hospital`
